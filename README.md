# 🔗 Encurtador de URLs em Python (Flask)

Um aplicativo web simples e eficiente desenvolvido em Python utilizando o framework Flask para encurtar links longos e redirecionar os usuários automaticamente.

## 🚀 Tecnologias Utilizadas
* **Python 3**
* **Flask** (Microframework web)
* **HTML/HTTP** (Manipulação de rotas e redirecionamento)
